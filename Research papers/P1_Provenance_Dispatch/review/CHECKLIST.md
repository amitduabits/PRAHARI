# P1 submission checklist (CCS / PETS / USENIX Security)

- [ ] Page limit and template correct for the chosen venue (CCS 12pp + refs; PETS 20pp; USENIX 13pp)
- [ ] Anonymised: no PRAHARI, no Yushu, no Gujarat Police, no author institution in text, figures, or the artefact repository
- [ ] Self-citations phrased in the third person
- [ ] Threat model stated explicitly, with what is out of scope
- [ ] Capsicum, XEngine, Ancile, WDAC, Privid cited before page 3
- [ ] Every abstract claim has a row in the claim-to-evidence table
- [ ] The leakage experiment (C5) is either run or its absence is stated as a limitation in the abstract's scope
- [ ] At least one results row where a baseline wins, with an explanation
- [ ] Ethics section: deployment context, IRB or equivalent statement, dual-use discussion
- [ ] Artefact: code, seeds, and instructions that reproduce every figure from a clean clone
- [ ] Licence chosen for released code
- [ ] Data statement: what was synthetic, what was measured, stated in the evaluation setup not buried
