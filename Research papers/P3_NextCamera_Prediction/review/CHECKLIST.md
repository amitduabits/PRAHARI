# P3 submission checklist (IJCAI / AAMAS / T-ITS)

- [ ] Real data: VeRi-776 obtained, licence signed, and CityFlow requested
- [ ] DukeMTMC explicitly declined, with the reason stated in the paper
- [ ] Makris, Tieu, Javed, Gambs cited in the first paragraph
- [ ] Global popularity prior implemented and reported
- [ ] Flashback implemented and reported
- [ ] A road-network baseline built from mapconstruction.org implementations, not a strawman
- [ ] Temporal split, stated, with window boundaries
- [ ] Macro-average over cameras in the main table
- [ ] Entropy ceiling reported with the next-location framing, not next-bin
- [ ] Coverage sweep with the cliff located, or its absence reported as a finding
- [ ] Cold-start ablation present
- [ ] Bootstrap CIs and a paired test against the strongest baseline
- [ ] Limitations section names bias inheritance and function creep, with citations
- [ ] Evaluation code and transition tables released even though raw plate data cannot be
- [ ] IJCAI: anonymised, page limit, reproducibility checklist completed
