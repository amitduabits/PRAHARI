\begin{frame}{The school-notebook analogy}
\begin{itemize}\itemsep0.65em

\begin{frame}{Integrator laws in the capture client}
\begin{itemize}\itemsep0.45em
\item Set \code{OPENCV\_FFMPEG\_CAPTURE\_OPTIONS=rtsp\_transport;tcp} before \code{import cv2}
\item Event time is PTS (\code{CAP\_PROP\_POS\_MSEC}), never arrival time, never declared FPS
\item Reconnect backoff starts at 2\,s and caps at 30\,s
\item Decoder warnings at join are logged, not fatal
\item PTS rewind or gap $>$ 5\,s is a scene cut (feeds loop)
\item Consume only. Do not wget \code{/stream/<id>}
\item Tests: \code{tests/test\_integrator\_laws.py}
\end{itemize}
\end{frame}

\begin{frame}{Why those laws (ten-year-old version)}
\begin{itemize}\itemsep0.55em
\item UDP across a firewall arrives as a broken picture that looks like a bad model
\item After join, extra frames may arrive fast. Wall-clock time invents flying cars
\item Feeds restart. Reconnecting in a tight loop is shouting at a locked door
\item The tape loops. At the splice, forget the old object ids
\item A downloaded \code{/stream} file is a fake dataset
\end{itemize}
\end{frame}
